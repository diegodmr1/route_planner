# Route Planner
A command-line route planner built to explore graph algorithms in Java.

## Status
Planning stage. No application code has been implemented yet.

## Goal
Model a transport network as a graph and compare routes by
number of connections and total distance.

## Planned features
- Load a small network from a local file.
- Find the route with the fewest connections using BFS.
- Find the shortest distance using Dijkstra's algorithm.
- Handle disconnected locations and invalid inputs.
- Compare algorithm behavior and performance.

## Planned stack
- Java
- Maven
- JUnit
- GitHub Actions

## Scope
The first version will use a small, fictional network.
Distances must be non-negative.
No external maps API or graphical interface is planned.
